# Moreton-Bay-Coral-Trajectories
Analysis pipeline for the Moreton Bay coral trajectories project.

The following code is for the Moreton Bay coral trajectories paper. Update the working path in the code for your directory and use the data file provided here (i.e., MB_coral_regrouped.csv).

The AI platform Claude Sonnet 5.5 (accessed 2026) was used for code development (e.g., debugging and correcting syntax), suggestions for analyses, and language editing of the manuscript. All AI-generated input was reviewed, tested, and revised by the authors, who confirmed the accuracy and reproducibility of the results and manuscript.
